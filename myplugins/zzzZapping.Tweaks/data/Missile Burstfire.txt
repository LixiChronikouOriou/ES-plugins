# Makes missile launchers fire like their appearances would suggest, e.g. Torpedo Launcher has
# two tubes, so it fires two torpedoes at once. Weapon DPS remains the same, this just shifts
# missiles away from a DPS orientation to a burst-damage one.
#
# However, the initial version of RW turned out to be OP, causing massive missile waves overloading
# any anti-missile (AM) system. Hence a more conservative estimation has been made for the burst count,
# not only based on the visuals but also taking a look on factions' AMs for orientation.
#
# Burst Reload = Reload / assigned Burst Count    # should not be <15, in that case burst count = 1
#
# Not currently done for pod size launchers as they already use the burst stats, so would be
# more involved, needing submunition definitions.


## HUMANS

outfit "Meteor Missile Launcher"
	weapon
		"burst count" 3
		"burst reload" 25
